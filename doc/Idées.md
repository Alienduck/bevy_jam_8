# Gameplay

## Potions

- Gigatux Pafux: Potion pour grandir le paff demandée par un PNJ un peu louche
- Roulux Tëtus: Potion qui fait devenir une personne rousse
- Diarux Atomux: Potion qui donne une diarrhée carabinée
## Joueur

- Le joueur ne connait pas les effets des potions, les PNJ eux n'ont qu'une vague idée d'à quoi ressemble la potion donc si le joueur essaie de donner une mauvaise potion le PNJ s'en rendra compte
